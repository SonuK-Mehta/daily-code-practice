# 🚀 DailyCodePractice

Welcome to **DailyCodePractice** – a personal repository to stay consistent, sharpen my coding skills, and maintain an active GitHub contribution streak.

Each day, I log coding exercises, problem-solving challenges, and small projects across multiple technologies:

This repo acts as my coding diary — a record of continuous learning and daily progress.

---

## 📁 Repository Structure

Each folder is named by the date (**DD-MM-YYYY**) and contains **subject-wise subfolders** to organize the day’s work:

```
daily-code-practice/
├── README.md
├── 01-05-2025/
│   ├── JavaScript/
│   │   └── array-problems.js
│   ├── React/
│   │   └── useState-example.jsx
│   ├── SQL/
│   │   └── joins.sql
│   ├── Node.js/
│   │   └── express-routing.js
│   ├── MongoDB/
│       └── schema-setup.js
```

✅ Each subject folder holds practice problems, code snippets, or learning notes specific to that topic.

✅ Every day’s work is organized by **date → subject → files**.
